# 🎓 نظام التنبؤ بنجاح الطلاب والإنذار المبكر (Student Success Prediction System)

مشروع متكامل للذكاء الاصطناعي وتعلم الآلة (Machine Learning) متصل بلوحة تحكم تفاعلية باستعمال **Streamlit**، يهدف إلى التنبؤ بالأداء الأكاديمي للطلاب واكتشاف الحالات المعرضة للرسوب مبكراً بناءً على نسبة الحضور، ساعات المذاكرة، والدرجات السابقة.

---

## 📌 نبذة عن المشروع
يهدف هذا النظام إلى تقديم حلول ذكية للمؤسسات التعليمية والمرشدين الأكاديميين للتدخل المبكر ودعم الطلاب الهامشيين أو المعرضين للرسوب قبل الامتحانات النهائية، مما يرفع من معدلات النجاح العامة.

---

## 🛠️ أبرز المميزات التقنية
- **خوارزمية التنبؤ**: تم استخدام نموذج **Logistic Regression** وتدريبه باستخدام `class_weight='balanced'` للتعامل مع عدم توازن البيانات (Class Imbalance).
- **حساسية عالية للرسوب (High Recall)**: حقق الموديل نسبة **Recall بلغت 91.07%** في التنبؤ بفئة الطلاب المعرضين للرسوب لتسهيل اكتشافهم مبكراً وتقليل نسبة الخطأ.
- **واجهة مستخدم احترافية**: تصميم عصري بأسلوب الزجاج (Glassmorphism UI) باستخدام CSS مخصص، يحتوي على كروت لمستويات الخطورة ومؤشرات تفاعلية للنسب الاحتمالية.
